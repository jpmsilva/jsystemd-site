About jsystemd provider for Keycloak

Keycloak provider that integrates Keycloak with systemd, telling it when Keycloak is ready and when it is stopping, and sending watchdog heartbeats and status updates. Installed as a single jar, which includes jsystemd-core, in the providers directory of Keycloak.
